## English localization

### Subtitle

8-Voice Analog Synthesizer

### Promotional text

Analog modeling, waveform memory, and POLY MOD in one instrument. Play standalone or as an AUv3 Instrument.

### Description

Aureline is an eight-voice polyphonic synthesizer combining the hands-on character of a classic analog instrument with distinctive waveform-memory sounds.

Its two oscillators, filter, envelopes, LFO, POLY MOD, and arpeggiator cover warm pads, powerful basses, digital game tones, and sound effects.

Features:

• Eight-voice polyphony
• Two oscillators
• Analog-modeled and waveform-memory sounds
• WAVE EDIT with touch-drawn waveforms
• POLY MOD
• Filter and amplifier envelopes
• LFO, arpeggiator, chord, and hold controls
• 50-voice library
• Voice and library file import/export
• External MIDI input
• AUv3 Instrument support

Play Aureline from its built-in keyboard as a standalone app, or load it as an AUv3 Instrument in a compatible host such as GarageBand.

## App Review information

### Sign-in

No sign-in or demo account is required.

### Review notes

Aureline is a standalone synthesizer and also includes an AUv3 Instrument extension.

Standalone test:
1. Launch Aureline.
2. Tap the on-screen keyboard; audio should play immediately.
3. Change a voice from the voice selector.
4. Open EDIT WAVE to draw and audition a waveform-memory sound.

AUv3 test in GarageBand:
1. Create or open a song.
2. Add an Audio Unit Extension instrument track.
3. Select Aureline.
4. Play it from GarageBand’s keyboard.

The app has no account, advertising, analytics, in-app purchases, subscriptions, or network-dependent features. Voice and library files are stored locally and are exported only through Apple’s document interfaces at the user’s request.

## Export compliance

Aureline does not implement proprietary or non-exempt encryption. It only uses encryption supplied by Apple’s operating system for standard platform services.
