Aureline Support

Aureline is an eight-voice analog-modeling synthesizer for iPhone and an AUv3 Instrument.

Using the AUv3 Instrument in GarageBand

  1. Open or create a GarageBand song.
  2. Add an Audio Unit Extension instrument track.
  3. Select Aureline.
  4. Play from GarageBand’s keyboard or a connected MIDI controller.

Voice files

.aurelinevoice stores one voice. .aurelinelibrary.xml stores all 50 voice slots. LOAD imports a file; STORE commits the current sound to its selected slot.

Troubleshooting

If audio is interrupted, reopen Aureline and confirm the device volume and audio route. In an AUv3 host, confirm that the Aureline instrument track is selected and receives MIDI.
